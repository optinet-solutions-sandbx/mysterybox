# Design system

The brand follows the **"Royal Blue Luxury" board** (2026-10-09): dark tones, a noble presence, timeless
prestige. Values on the board: exclusive, surprising, prestigious, timeless. The trading name is
still open; the board's **M** monogram stands in for it.

| Brand decision | Where it plugs in |
|---|---|
| Name, monogram, tagline, descriptor, box side line, entity, minimum age | `web/src/config/brand.ts` |
| Palette and semantic roles | `:root` in `web/src/app/globals.css` |
| Fonts | The `next/font` calls in `web/src/app/layout.tsx` (`--font-display-face`, `--font-body`, `--font-numeric`) |
| Box finishes | `materials` in `web/src/components/box3d/box-3d.tsx` |
| Product imagery | `image` on items (`web/src/data/items.ts`, `config/media.ts`) |

## Palette (from the board)

| Name | Hex | Role |
|---|---|---|
| Obsidian Black | `#0B0B0D` | Page background (`--bg`) |
| Midnight Navy | `#0F1C3F` | Panels and surfaces (`--surface`) |
| Deep Indigo | `#1A2456` | Cards and nested surfaces (`--surface-2`) |
| Royal Sapphire | `#1E3A8A` | Light and highlights: glows, marble veins, lid lining (`--sapphire`, brighter `--glow`) |
| Champagne Gold | `#C2A46E` | Foil: type, edges, monogram, the primary button (`--accent`, `--foil`) |
| Soft Ivory | `#E8E1D6` | Text (`--fg`; `--muted` and `--subtle` are ivory mixed toward obsidian) |

**Gold is foil, never flat paint.** `--foil` is a multi-stop champagne gradient used through
`text-foil`, `bg-foil` and `btn-foil` (which adds a light sweep on hover). Hairlines (`--line`) are gold
at 24%.

**Rarity colors** stay in the gaming order players already read (common, uncommon, rare, epic,
legendary), retuned to sit on navy. Legendary is gold.

## Type

| Role | Face | Notes |
|---|---|---|
| Display, prices, monogram | **Cinzel** (`font-display`) | Roman inscriptional capitals, echoing the engraved "ROYAL BLUE LUXURY" on the board. Lowercase renders as small capitals, so headings are written in sentence case and read as caps. Prices and big numbers use it too, through `text-foil` |
| Text and UI | **Jost** (`font-sans`) | Geometric and quiet; italic for the descriptor line |
| Technical strings | Geist Mono (`font-mono`) | **Only** seeds, hashes and nonces |

Scale: the hero H1 is `clamp(3.2rem, 8.4vw, 8.2rem)` at leading 0.92, page H1s are 5xl → 7xl, section
H2s are 4xl → 6xl, and body text is 16–18px at relaxed leading.

**Avoid:**
- a tracked-caps label above every heading;
- accenting a single word in a headline;
- monospace prices (that is icybox's signature);
- arrows appended to buttons.

## Texture and light

- **Marble** (`bg-marble`): sapphire veins generated by an SVG turbulence filter (no image asset, tiles
  seamlessly). Used under the hero and box stage floors and in the footer.
- **Leather** on `Box3D` faces: a fine noise overlay.
- **Grain** (`.grain`): a fixed 7% overlay over the whole page.
- **Light** is always sapphire, or warm white-gold *from inside the box*. Use radial gradients, never
  large `blur()` filters (they cost more and can tile with seams).

## The box (`Box3D`)

A real CSS-3D box built to the board's proportions (W, H = 0.62W, D = 0.8W):
- leather faces with gold piping;
- a foil **M** and "MORE THAN A BOX" on the front, and "MYSTERY BEYOND THE ORDINARY" on the side;
- a hinged lid with a sapphire satin lining;
- interior walls, and warm light pooled at the opening;
- a beam and gold dust when open.

Five finishes map to tiers: `obsidian`, `navy`, `sapphire`, `ivory`, `gold`. Phase 1+ can replace it
with real renders while keeping the props (`open`, `viewX`, `viewY`, `tilt`, `float`, `shake`).

## Components

| Component | Notes |
|---|---|
| `Button` / `ButtonLink` | `primary` = foil with a sweep; `secondary` = navy glass with a gold hairline; `ghost` = text with a gold underline on hover |
| `PageHeader`, `Container`, `SectionHeading`, `Eyebrow` | Sections use `py-28`, `max-w-7xl` |
| `Modal`, `useDialog` | Focus in, Escape, scroll lock (Lenis-aware), focus return |
| `ItemArt` | Cut-out photo on a spotlit navy plate tinted by rarity; otherwise a gold-line drawing (`item-drawings.tsx`, 21 drawings) |
| `BoxCard` | The 3D box in its finish; the lid lifts on hover; top piece and foil price |
| `InsideGrid` | Every piece: rarity bar, rarity, odds pill, brand, name, listed value |
| `OddsTable` | Every piece with value, odds and roll range |
| `Reel`, `RevealOverlay`, `BoxStage` | The core loop (see [05-motion-spec.md](05-motion-spec.md)) |
| `Wordmark` | Foil M in a fine gold ring (header) |
