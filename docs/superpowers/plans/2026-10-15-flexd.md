# FLEXD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `flexd/`, a third site that is a copy of `play/` re-branded as FLEXD and re-skinned in matte velvet purple and gold.

**Architecture:** `flexd/` starts as a byte copy of `play/` (from `origin/play`) on the local branch `flexd`, then changes in place: the mark, brand strings and storage keys, dark only, the chest's materials, the colour tokens, the type, and a few shell components. `play/` and `web/` are not touched. Repo-level checks (no Grail Noir left, palette values, contrast, matte finishes, prices in Playfair) are Vitest tests that read the source; the whole loop is covered by a copy of the play e2e script.

**Tech Stack:** Next.js 16.4 (App Router), React 19.3, TypeScript strict, Tailwind v4, Motion 14, three.js 0.180, Zustand 5, Vitest, sharp, Python Playwright 1.62 (e2e and box stills).

**Spec:** `docs/superpowers/specs/2026-10-15-flexd-design.md`

## Global Constraints

- Work only in `flexd/`, `scripts/render_box_stills.py`, `scripts/e2e_flexd.py`, root `CLAUDE.md` and `docs/`. `play/` and `web/` stay identical to `origin/play`.
- Branch `flexd` has no upstream. Commit locally after each task. **Never push** without the user's go-ahead, and never to `main` or `play`.
- Next 16.4 has changed APIs: read the guide in `flexd/node_modules/next/dist/docs/` before using a Next API this codebase doesn't already use (`flexd/AGENTS.md`).
- Dark only: no `[data-theme="light"]` tokens, no theme switch, `<html data-theme="dark">` fixed, `theme-color` `#0A0510`.
- Palette (from the sheet): ground `#0A0510`, surface `#160A22`, surface-raised `#22112F`, hairline `#3D2152`, velvet-900 `#2A0B45`, velvet-700 `#3F1366`, velvet-500 `#5B1E92`, velvet-300 `#A374E0`, velvet-100 `#DCC8F0`, gold-700 `#8C6A2E`, gold-500 `#C2A05A`, gold-300 `#E6CF9A`, gold-100 `#F0DDAE`, champagne `#F4E9D2`, muted `#B3A3C4`, success `#7FB89A`, danger `#E07A86`.
- Less shiny: no clear coat, iridescence, light sweep or purple glow on velvet; velvet buttons are a near-flat fill; gold keeps its metallic sheen.
- Tokens only in components (semantic utilities, never raw hex). Exceptions: `chest-finishes.ts` (three.js materials), the share card's colour table in `card.tsx` (images can't read CSS) and the layout's `themeColor`.
- Type: Cinzel for headlines and names, Playfair Display for prices and amounts, Jost for text.
- No new third-party assets. Copy rules from the root `CLAUDE.md` still apply (no "win", "profit", "investment", "guaranteed"; keep the 18+ lines).
- Performance: no runtime SVG filters on large elements, no blend modes on large or fixed layers, no `blur()` or `backdrop-filter` on moving or repeated elements.
- Motion and sound unchanged from `play/` (one ease, `[0.22, 1, 0.36, 1]`).
- All app commands run from `flexd/`. `$SCRATCH` means this session's scratchpad directory (outside the repo).
- Verification never writes into `play/` (the stills script must be given the `flexd` argument).

## Review Focus

1. A visitor whose system is set to light mode still gets the dark site, with no theme switch anywhere. Test: Task 8, e2e "dark under a light system preference".
2. 320 px wide phones: Cinzel capitals are wider than heavy Jost, so no page may scroll sideways. Test: Task 8, e2e "320 wide".
3. One-word or padded box names ("Vanity", " Grail Reserve ") get a sensible accent: none for one word, the last word otherwise. Test: Task 6, `accent.test.ts`.
4. Text on the new tokens stays readable (at least 4.5:1): text, muted, subtle, gold and amethyst on ground and surface, gold labels on velvet. Test: Task 5, `tokens.test.ts`.
5. Link previews and story images show FLEXD's colours and mark, not burgundy. Tests: Task 2, `mark.test.ts` (raster mark with transparency); Task 8, e2e pixel check on the link preview.

// Draws the FLEXD placeholder mark (src/config/mark.json) to the files the site serves:
// public/brand/flexd-mark.webp (gold on transparency, 720x480; also the chest lid's inlay mask)
// and src/app/icon.png (512) / src/app/apple-icon.png (180), gold on the ground colour.
// Run from flexd/: npm run brand:assets
import { readFile } from "node:fs/promises";
import { fileURLToPath } from "node:url";
import sharp from "sharp";

const at = (p) => fileURLToPath(new URL(`../${p}`, import.meta.url));
const mark = JSON.parse(await readFile(at("src/config/mark.json"), "utf8"));
const SHEEN = [["0", "#8C6A2E"], ["0.3", "#E6CF9A"], ["0.5", "#B08A45"], ["0.7", "#F0DDAE"], ["1", "#9C7838"]];
const GROUND = "#0A0510";

function svg(width, height, background) {
  const { width: vw, height: vh } = mark.viewBox;
  const room = background ? 0.8 : 1;
  const scale = Math.min((width * room) / vw, (height * room) / vh);
  const tx = (width - vw * scale) / 2;
  const ty = (height - vh * scale) / 2;
  const stops = SHEEN.map(([o, c]) => `<stop offset="${o}" stop-color="${c}"/>`).join("");
  const paths = mark.paths.map((p) => `<path d="${p.d}" fill-rule="${p.rule}" fill="url(#sheen)"/>`).join("");
  return `<svg xmlns="http://www.w3.org/2000/svg" width="${width}" height="${height}" viewBox="0 0 ${width} ${height}">
<defs><linearGradient id="sheen" gradientUnits="userSpaceOnUse" x1="0" y1="0" x2="${vw}" y2="${vh}">${stops}</linearGradient></defs>
${background ? `<rect width="100%" height="100%" fill="${background}"/>` : ""}
<g transform="translate(${tx} ${ty}) scale(${scale})">${paths}</g></svg>`;
}

await sharp(Buffer.from(svg(720, 480))).webp({ quality: 92, alphaQuality: 100 }).toFile(at("public/brand/flexd-mark.webp"));
await sharp(Buffer.from(svg(512, 512, GROUND))).png().toFile(at("src/app/icon.png"));
await sharp(Buffer.from(svg(180, 180, GROUND))).png().toFile(at("src/app/apple-icon.png"));
console.log("wrote public/brand/flexd-mark.webp, src/app/icon.png, src/app/apple-icon.png");

- [ ] **Step 1: Add the source helper** — `flexd/src/test-utils/source.ts`

```ts
import { readdirSync, readFileSync, statSync } from "node:fs";
import { join, relative } from "node:path";

const ROOT = process.cwd();
const TEXT = /\.(tsx?|css|json|md|mjs|svg|txt)$/;

function files(dir: string): string[] {
  return readdirSync(dir).flatMap((name) => {
    const p = join(dir, name);
    return statSync(p).isDirectory() ? files(p) : TEXT.test(name) ? [p] : [];
  });
}

/** Lines under `dirs` (relative to flexd/) that match `pattern`, as "path:line: text". */
export function grepSource(pattern: RegExp, dirs: string[], skip: string[] = []): string[] {
  return dirs
    .flatMap((d) => files(join(ROOT, d)))
    .map((f) => [relative(ROOT, f).replaceAll("\\", "/"), f] as const)
    .filter(([rel]) => !skip.includes(rel))
    .flatMap(([rel, f]) =>
      readFileSync(f, "utf8")
        .split(/\r?\n/)
        .flatMap((line, i) => (pattern.test(line) ? [`${rel}:${i + 1}: ${line.trim()}`] : [])),
    );
}
```

`flexd/src/lib/accent.ts`:

```ts
/** Splits a name so its last word can be set in amethyst ("The Time" + "Room"). One word: no accent. */
export function splitAccent(name: string): { lead: string; accent: string | null } {
  const trimmed = name.trim();
  const i = trimmed.lastIndexOf(" ");
  if (i < 0) return { lead: trimmed, accent: null };
  return { lead: trimmed.slice(0, i), accent: trimmed.slice(i + 1) };
}
```

`flexd/src/components/ui/accent-name.tsx`:

  if (!accent) return <>{lead}</>;
  return (

    </>
  );
}
